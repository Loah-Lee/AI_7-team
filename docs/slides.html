아키텍처 개요

Architecture Overview

프로젝트 개요

입찰메이트는 대규모 B2G 입찰 RFP 문서에서 필요한 정보를 빠르고 정확하게 찾아주는 AI 기반 질의응답 시스템입니다.

📊 멀티소스

CSV + PDF + HWP
통합 처리

🔍 스마트 검색

ChromaDB 벡터 검색
+ 메타데이터 필터

🤖 LLM 기반

질문 의도 파악
+ 간결한 답변

기술 스택

언어: Python 3.10+
LLM: OpenAI gpt-4o-mini
임베딩: text-embedding-3-small (1536 dim)
벡터 DB: ChromaDB 0.4.0+
PDF: pdfplumber 0.10.0+
HWP: LibreOffice + pyhwpx
웹: Streamlit 1.20+
한국어: sentence-transformers 2.2.0+
데이터: pandas 2.0.0+
트레이싱: LangSmith

QueryIntentParser

LLM을 사용하여 질문 의도를 파악하고, 신뢰도가 낮으면 정규식으로 재분석

def parse(self, query: str) -> QueryIntent:
    if self.client:
        intent = self._parse_with_llm(query)      # 1차: LLM 분석
        if intent.confidence < 0.7:
            regex_intent = self._parse_with_regex(query)  # 2차: 정규식
            if regex_intent.confidence > intent.confidence:
                intent = regex_intent
        return intent
    return self._parse_with_regex(query)

RFPAnswerGenerator

역할

  • 검색된 문서 컨텍스트 기반 답변 생성
  • RFP 핵심 정보 추출
  • 간결하고 자연스러운 답변

특징

  • temperature: 0.1 (정확성)
  • max_tokens: 2000
  • 자동 정제 (태그 제거)

RAGChatbotV17 - 메인 클래스

class RAGChatbotV17:
    def __init__(self, data_dir, db_path):
        # 초기화
        self.answer_generator = RFPAnswerGenerator(client)
        self.vector_store = VectorStore(db_path)
        self.query_parser = QueryIntentParser(client)
        self.conversation = ConversationContext(max_history=5)
        self._load_documents()

    def answer(self, query: str) -> dict:
        # 1. 기관명 추출
        # 2. 벡터 검색 (top_k=30)
        # 3. 답변 생성 또는 요약 반환
        return {"answer": ..., "found": bool}

TextCleaner - 텍스트 정제

  • normalize_newlines: 연속된 줄바꿈 정리 (`\n{3,}` → `\n\n`)
  • remove_extra_spaces: 연속 공백 제거
  • remove_special_chars: 특수 문자 제거
  • extract_sentences: 문장 추출
  • extract_keywords: 키워드 추출 (불용어 제거)

불용어: 이다, 하다, 되다, 있다, 없다, 같다, 아니다, 이, 그, 저, 것, 등, 및

답변 원칙 (RFP_SYSTEM_PROMPT)

  1. 자연스러운 문장 - 틀에 박히지 말고 말하듯이
  2. 질문에 먼저 답변 - 묻는 것에 1-2문장으로 직접 답하고, 추가 정보 제공
  3. 정확한 정보 - 숫자, 날짜는 구체적으로
  4. 있는 정보만 - 문서에 없으면 "문서에 명시되어 있지 않음"
