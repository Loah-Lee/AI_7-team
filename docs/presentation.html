01

시스템 개요

프로젝트 소개

입찰메이트는 RFP(제안요청서) 문서를 기반으로 한 AI 기반 질의응답 시스템입니다.

📊 멀티소스 통합

CSV + PDF + HWP
마크다운으로 통합 변환

🔍 스마트 검색

ChromaDB 벡터 검색
+ 메타데이터 필터링

🤖 LLM 기반 파싱

질문 의도 분류
+ 간결한 답변 생성

기술 스택

LLM: OpenAI gpt-4o-mini
임베딩: text-embedding-3-small (1536dim)
벡터 DB: ChromaDB + Cosine Similarity
프레임워크: LangGraph + Streamlit
PDF 처리: pdfplumber
HWP 처리: LibreOffice 변환
트레이싱: LangSmith
언어: Python 3.10+

사용 예시

질문 유형별 처리

질문 유형 예시 처리 방식
기관 조회 "고려대학교 사업비는?" org 레지스트리 직접 검색
랭킹 조회 "TOP5 기관은?" 사업비 순 정렬
범위 필터링 "5억에서 10억 사이" min/max 조건 필터링
카테고리 검색 "IT 관련 사업?" 사업명 키워드 검색
후속 질문 "그거 언제야?" 대화 컨텍스트 활용

후속 질문 처리 예시
