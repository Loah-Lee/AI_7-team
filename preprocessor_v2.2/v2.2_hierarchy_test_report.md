```

L1 [2..3]   "-"
  L2 [3..3]     "목차"

  L2 [6..6]     "추진개요"
L1 [8..11]  "Ⅱ"
  L2 [9..11]    "사업추진방안"
L1 [13..24] "Ⅲ"
  L2 [14..24]   "사업추진내용"
L1 [26..85] "Ⅳ"

L1 [87..89] "Ⅴ"
  L2 [88..89]   "입찰관련사항"
L1 [91..99] "Ⅵ"
  L2 [92..99]   "제안서작성요령"
L1 [101..130] "Ⅶ"
  L2 [102..115] "별지서식및붙임"
  L2 [116..116] "합의각서"
  L2 [117..117] "청렴서약서"
  L2 [118..118] "근로자권리보호이행서약서"
  L2 [119..119] "(보안서약서 업체용)"
  L2 [120..120] "(보안서약서 개인용)"
  L2 [121..123] "보안특약사항"
  L2 [124..124] "보안위약금부과기준"
  L2 [125..130] "누출금지대상정보"
```

- L1은 parser가 검출한 H1 헤더(로마숫자 장 구분)에 대응
- L2는 H2 헤더(실제 섹션 제목)에 대응
- `parent_uid`로 L2 → L1 관계 추적 가능
- `start_order`/`end_order`로 해당 섹션의 chunk 범위 정의

## 6. 성능 이슈

### FTS5 + chunks 단일 JOIN 쿼리 타임아웃

v2.2 설계에서 제안한 단일 JOIN 패턴:

```sql
-- 이 쿼리는 120초 이상 소요 (실용 불가)
SELECT c.rowid, c.text, bm25(sparse) AS score
FROM sparse
JOIN chunks c ON sparse.uid = json_extract(c.metadata, '$.uid')
WHERE sparse.nouns MATCH '시스템'
  AND json_extract(c.metadata, '$.doc_id') = ?
  AND json_extract(c.metadata, '$.chunk_order') BETWEEN ? AND ?
ORDER BY bm25(sparse)
LIMIT 5;
```

**원인**: FTS5 가상 테이블의 특성상, 외부 테이블과의 JOIN에서 SQLite 옵티마이저가 인덱스를 효과적으로 활용하지 못함.

### 실용적 대안: 2단계 쿼리

```sql
-- Step 1: FTS5 단독 검색 (doc_id 필터 가능, 빠름)
SELECT uid, bm25(sparse) AS score
FROM sparse
WHERE doc_id = ? AND nouns MATCH '시스템'
ORDER BY bm25(sparse)
LIMIT 30;

-- Step 2: uid로 chunks 조회 + scope 필터 (인덱스 활용, 빠름)
SELECT json_extract(metadata, '$.chunk_order'), text
FROM chunks
WHERE json_extract(metadata, '$.uid') = ?;
-- Python에서 chunk_order BETWEEN start AND end 필터
```

| 단계 | 소요 시간 |
|------|----------|
| Step 1: FTS5 (doc_id 내 30건) | ~1.5s |
| Step 2: uid별 chunks 조회 (30건) | ~0.06s |
| **합계** | **~1.6s** |

### 추가 인덱스 (코드 반영 완료)

테스트 과정에서 JOIN 성능 개선을 위해 2개 인덱스를 추가 생성하였으며, `storage_step5.py`의 `ensure_indexes()`에 반영 완료:

```sql
CREATE INDEX IF NOT EXISTS idx_chunks_uid ON chunks(json_extract(metadata, '$.uid'));
CREATE INDEX IF NOT EXISTS idx_chunks_doc_id ON chunks(json_extract(metadata, '$.doc_id'));
```

`ensure_indexes()`가 기존 3종 + 추가 2종 = **총 5종 인덱스**를 자동 생성한다.
