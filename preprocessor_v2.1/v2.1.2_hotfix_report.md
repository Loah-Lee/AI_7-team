## 적용 내용

**파일**: `storage_step5.py` — `assign_uids()` 함수 전체 교체

| 항목 | Before (v2.1.1) | After (v2.1.2) |
|------|-----------------|-----------------|
| 빈 chunk 리스트 | 무시 (빈 루프) | `RuntimeError` 발생 |
| `doc_id` 누락 | `.get('doc_id', 'unknown')` 으로 fallback | `RuntimeError` 발생 |
| `doc_id == "unknown"` | 허용 (fallback 값) | `RuntimeError` 발생 |
| `doc_id` 타입/공백 | 검증 없음 | `isinstance(str)` + `strip()` 검증, 실패 시 `RuntimeError` |
| `metadata` 부재 | KeyError 발생 가능 | 빈 dict 자동 생성 후 진행 |
| `metadata` 타입 | 검증 없음 | `isinstance(dict)` 검증, 실패 시 `RuntimeError` |
| `metadata.doc_id` | 미포함 | `chunk['metadata']['doc_id'] = doc_id` 명시적 삽입 |

**아키텍처 모델**: Deterministic Replacement Model
- SHA-256 기반 doc_id 결정론적 생성
- Fail-Fast 계약 위반 시 즉시 종료
- 재실행으로 상태 복원 가능
