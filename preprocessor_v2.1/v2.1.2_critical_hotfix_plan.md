# Core Upsert Contract

The system is considered safe only if:

1. Every chunk contains `doc_id`.
2. `metadata` contains the identical `doc_id`.
3. `doc_id` must never equal `"unknown"`.
4. Each document must produce at least one chunk.
5. Any violation triggers immediate termination (Fail-Fast).
6. Regeneration of identical input reproduces identical database state.

There are no fallback modes.

Replace the existing function entirely with the following:

```python
from typing import List, Dict

def assign_uids(chunks: List[Dict]) -> None:
    """
    Assign UIDs and enforce Upsert contract (Fail-Fast architecture).
    """

    # Contract 1: chunk list must not be empty
    if not chunks:
        raise RuntimeError(
            "Critical: empty chunk list detected before UID assignment"
        )

    doc_counters: Dict[str, int] = {}

    for i, chunk in enumerate(chunks):

        # Contract 2: doc_id must exist
        if 'doc_id' not in chunk:
            raise RuntimeError(
                f"Critical: chunk index {i} missing 'doc_id' before UID assignment"
            )

        doc_id = chunk['doc_id']

        # Contract 3: validate doc_id
        if not isinstance(doc_id, str) or not doc_id.strip():
            raise RuntimeError(
                f"Critical: invalid doc_id detected at chunk index {i}"
            )

        if doc_id == "unknown":
            raise RuntimeError(
                f"Critical: forbidden fallback doc_id 'unknown' "
                f"at chunk index {i}"
            )

        # Generate deterministic UID
        idx = doc_counters.get(doc_id, 0)
        uid = f"{doc_id}_{idx}"
        chunk['uid'] = uid

        # Ensure metadata existence
        if 'metadata' not in chunk or chunk['metadata'] is None:
            chunk['metadata'] = {}

        if not isinstance(chunk['metadata'], dict):
            raise RuntimeError(
                f"Critical: metadata must be dict (chunk index {i})"
            )

        # Contract 4: enforce metadata consistency
        chunk['metadata']['uid'] = uid
        chunk['metadata']['doc_id'] = doc_id

        doc_counters[doc_id] = idx + 1
```

Fail-Fast behavior is mandatory.
No alternative return-based behavior is permitted.

    SQLiteVec.from_texts(...)

Actual runtime model:

    DELETE (connection A)
    INSERT (connection B via SQLiteVec)

Therefore:

Full cross-operation SQLite transactional atomicity

# 3. Atomicity Design Decision

This is intentional.

The system does NOT depend on ACID-level cross-connection atomic guarantees.

Instead, it depends on:

- Deterministic SHA-256 doc_id
- Idempotent document regeneration
- Re-execution safety
- Fail-Fast contract enforcement

If a process crash occurs between DELETE and INSERT
(e.g., OOM, forced termination, hardware interruption),
the system can safely restore state by rerunning the pipeline.

This architectural model is defined as:

Deterministic Replacement Model
