## 핵심 원칙

Dense Index는:
- 테이블은 유지
- 동일 doc_id에 해당하는 기존 벡터만 DELETE
- 새 chunk 벡터 INSERT

Append 금지.
전체 Drop 금지.
반드시 Doc-level Replace 구현.

## 1️⃣ storage_step5.py 수정

### A. upsert_dense_vectors 함수 추가

```python
def upsert_dense_vectors(db_path: str, chunks: List[Dict], model_name: str) -> int:
    """
    Doc_ID 기반 Dense Upsert 수행.
    - 기존 동일 doc_id 벡터 삭제
    - 새 벡터 삽입
    Returns: inserted vector count
    """
```

---

### B. 구현 로직 (필수)

1. embedding 모델 로드

```python
embeddings = SentenceTransformerEmbeddings(model_name=model_name)
```

2. DB 연결

```python
with sqlite3.connect(db_path) as conn:
    cursor = conn.cursor()
```

3. chunks 테이블 존재 여부 확인  
   없으면 SQLiteVec.from_texts(...)로 생성

4. 삭제 대상 doc_id 집합 추출

```python
doc_ids = {c['doc_id'] for c in chunks}
```

5. 기존 벡터 삭제 (JSON metadata 기반)

```sql
DELETE FROM chunks
WHERE json_extract(metadata, '$.doc_id') = ?
```

※ SQLite JSON1 extension 사용

6. 새 벡터 삽입

```python
SQLiteVec.from_texts(
    texts=[c['content'] for c in chunks],
    embedding=embeddings,
    table="chunks",
    db_file=db_path,
    metadatas=[c['metadata'] for c in chunks]
)
```

7. 삽입된 개수 반환

---

### 구현 전략 (Hotfix 최소 요구)

1. split_into_sections에서 page 추적은 유지
2. create_chunks_from_section 내부에서:

   - current_chunk_page_start
   - current_chunk_page_end

   두 변수 추가

3. block 처리 시
   해당 block이 생성될 당시의 page 번호 기록

4. chunk 저장 시:

```python
metadata['page_start'] = min(collected_pages)
metadata['page_end'] = max(collected_pages)
```

⚠ section.page_end 직접 복사 금지

완전 정밀 추적이 아니어도 됨.
섹션 전체 범위 복사만 제거하면 Hotfix 기준 충족.
